Informativa sulla privacy

Ultimo aggiornamento: 25 ottobre 2026

Questa informativa descrive quali dati tratta l'applicazione vialenta-upload e come lo fa. L'applicazione è uno strumento personale. La usa solo il proprietario del canale YouTube Vialenta, per gestire il proprio canale.

1. Dati a cui l'applicazione accede

Con l'autorizzazione dell'utente, data tramite Google OAuth, l'applicazione richiede questi permessi:

  • youtube.upload: per caricare video sul canale dell'utente.
  • youtube: per leggere nome e identificativo del canale, impostare le miniature, aggiungere video alle playlist e leggere lo stato dei video caricati.

L'applicazione non legge commenti, iscritti, messaggi, cronologia di visualizzazione, dati di pagamento né altri dati dell'account Google. Usa solo i dati necessari alle funzioni elencate.

2. Come vengono usati i dati

I dati servono solo a caricare e configurare i video sul canale dell'utente, su sua richiesta. Non vengono usati per pubblicità, profilazione, analisi di mercato o addestramento di modelli di intelligenza artificiale. Non vengono venduti.

3. Dove vengono conservati

  • Token di autorizzazione OAuth: è conservato sul computer dell'utente (file token.json) oppure come variabile d'ambiente privata nell'ambiente di esecuzione cloud che l'utente usa per lanciare lo script. Non è pubblicato né inserito in repository pubblici.
  • Dati dei video: titolo, descrizione, identificativo e link dei video caricati. Sono registrati in file di testo e di log nella cartella di lavoro dell'utente, per tenere traccia dei caricamenti.

L'applicazione non ha un server proprio e non raccoglie dati su server dell'autore.

4. Condivisione con terzi

I dati vengono inviati solo a Google/YouTube, attraverso i Servizi API di YouTube, per eseguire le operazioni richieste. Quando l'utente esegue lo script in un ambiente cloud di terze parti, quell'ambiente esegue il codice per suo conto. Nessun dato viene condiviso con altri soggetti.

5. Servizi API di YouTube e Google

L'applicazione usa i Servizi API di YouTube. L'uso dei dati è conforme alle Norme relative ai dati utente dei servizi API di Google, inclusi i requisiti di uso limitato (Limited Use). Per il trattamento dei dati da parte di Google valgono le Norme sulla privacy di Google.

6. Conservazione e cancellazione

Il token resta valido finché l'utente non lo revoca. I file di log e di registro restano nella cartella dell'utente finché lui non li cancella. Per eliminare tutti i dati basta:

  • revocare l'accesso dell'applicazione dalla pagina Autorizzazioni dell'account Google;
  • cancellare il file token.json, le variabili d'ambiente in cui è salvato il token e le cartelle di log.

7. Cookie e sito web

Queste pagine informative non usano cookie, strumenti di analisi o tracciamento.

8. Modifiche

Se l'applicazione cambierà il modo in cui tratta i dati, questa pagina verrà aggiornata, insieme alla data in alto.
